Task 2: Website Traffic Analysis & Anomaly Detection

Overview

This project focuses on analysing website traffic using Google Analytics 4 (GA4) Demo Account to identify unusual traffic spikes and drops and investigate their possible causes.

Objective

To identify three unusual website traffic patterns and analyse the possible reasons behind them.

Tools Used

* Google Analytics 4 (GA4)
* Google Merchandise Store Demo Account

Tasks Performed

* Analysed website traffic reports.
* Examined user and session trends.
* Identified three unusual traffic spikes or drops.
* Investigated traffic sources and channel groups.
* Documented observations and possible explanations.

Analysis

Three unusual traffic patterns were identified and examined based on available analytics data. Possible explanations were recorded by comparing traffic sources and relevant metrics.

Key Learnings

* Understanding website traffic patterns.
* Identifying unusual increases and decreases in traffic.
* Analysing traffic sources and user engagement.
* Developing analytical and anomaly detection skills.

Outcome

Gained practical experience in website traffic analysis, anomaly identification, and data-driven investigation using Google Analytics 4.
